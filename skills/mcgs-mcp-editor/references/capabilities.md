# 能力与证据分级

维护基线：2026-10-17。运行时以 `scripts/kind_registry.py` 和具体命令的校验为准；本表不能代替目标模板的完整哈希和字段取证。

## 当前正式入口

| 能力 | 工具入口 | 已有证据与范围 |
| --- | --- | --- |
| MCP 数据库和完整窗口记录检查 | `mcp_tool.py inspect` | 逐窗校验记录边界及 trailer，输出成功/拒绝状态和汇总；不解释全部内部字段 |
| 窗口身份与导航一致性 | `inspect` / `--reference-profile` | 独立定位已识别尾部的名称/ID并与窗口行对照；导航仅检查精确哈希清单指定的字段，未覆盖项单列 |
| 标签改字 | `patch` / `string`，0x5008 | 已有变长中文及宿主显示/属性证据 |
| 输入框改绑与上下限 | `input_binding` / `input_range`，0x5025 | 同步既有变量名称及 ID；范围为 max/min；不创建变量 |
| 标准按钮事件 | `event`，0x5027 | 源码与字节数组一起替换，已验证受限条件脚本；不是全部按钮类型 |
| 矩形编辑 | `rectangle` | **仅 5008/5025/5027/5028/503C/503D 六类**；偏移必须由具体模板提供 |
| 两份图形样本的受限横移 | `horizontal_move` | 5004 矩形、5006 椭圆各一份 92 B 样本；只归一化横向原点后比较完整指纹，其他字节必须保持 |
| 其他已登记类文字 | `string` | 除 5026 外仅等长；不证明名称/绑定/多语言引用可任意替换 |
| 同窗口控件克隆 | `action=clone` | 完整记录克隆并检查同窗口新名；未知全局 ID 和资源引用仍需宿主检查 |
| 模板窗口复制 | `new_windows` | 复制窗口行及原始内容；历史样本有打开、Ctrl+E、保存重开证据，不等于通用跨窗口克隆 |
| 数值脚本编译/静态检查/仿真 | `script_tool.py compile/inspect/simulate` | int32、变量、加法、多语句、嵌套 If/Else 与六种比较；不支持完整 BASIC |

22 类是类型身份登记数，不是 22 类完整编辑器。0x5026 已识别但当前所有显式字段编辑仍拒绝；0x5030 仍未登记。0x5039 仅有等长文字入口，不能借此修改动作标志或变长动作名。

## 几何实验与正式入口的区别

2026-10-17 对 21 份现存几何候选独立回读：21/21 的目标 payload 与声明补丁一致，其他记录、窗口前缀、trailer 及其他表保持。宿主结果来自当时的操作者确认，并非此次重新操作 GUI。

| 实验样本 | payload 字节 / 偏移 | 操作与证据 | 当前正式 rectangle |
| --- | --- | --- | --- |
| 503C 下拉框 | 498 / +24 | 横移、改宽；坐标、Ctrl+E、展开选值经宿主确认 | 有，仍逐模板查证 |
| 503D DLL 两种布局 | 438 / +12；591 / +24 | 各横移、改宽；宿主反馈及保存文件回读 | 有，不能统一套偏移 |
| 5004 / 5006 | 92 / +12 | 横移；打开、坐标、Ctrl+E 经宿主确认 | 无通用 rectangle；有单独的样本限定 horizontal_move |
| 5002 / 5005 / 5009 / 5023 / 5031 / 503A | 92 / 100 / 106 / 137 / 662 / 6667，均 +12 | 横移；历史反馈无报错，保存件回读 | 无 |
| 5029 / 502D / 502E / 5032 / 5033 | 383 / 1307 / 2192 / 587 / 1520，均 +12 | 横移；历史反馈无报错，保存件回读 | 无 |
| 502A / 5039 | 713 / 3053，均 +12 | 小横移；历史反馈无报错，保存件回读 | 无 |

“无报错”不能自动覆盖所有属性、事件、曲线行为和任意缩放。直线 +12 的四个 int32 是端点；其他图形样本是包围盒候选/已观察几何。表中记录长度只帮助找到样本，不能作为完整布局签名。

5004/5006 的新入口保留完整 payload 哈希和坐标原值校验。样本指纹将 `(left,top,right,bottom)` 归一化为 `(0,top,right-left,bottom)` 后哈希，允许反复横移，但尺寸、纵坐标、样式、名称或任何不明字节改变都会拒绝。一次清单只允许该横移操作，不支持同时改名、改样式或克隆。任意新位移的宿主结果仍需按输出验收；新增实现的字节回归不冒充重新进行 GUI 验收。

生产样本曾出现同为 502A 的 90 条记录、19 种长度，没有一条等于已验收的 713 B。不得凭 kind 相同，将单模板位移结论推广到全部生产记录。需要开放新入口时，先实现布局/原值校验和未知布局拒绝，再以对应宿主实验确认操作范围。

## 尚未提供的功能与下一步

| 请求 | 当前处理 |
| --- | --- |
| 任意变量新增、改名传播、类型变更 | 先做原生新增/删除后再新增对照，核对计数、ID、绑定及引用；无 CLI 创建接口 |
| 任意设备新地址 | 走宿主原生流程；字节新增已有加载丢弃反例 |
| 5039 动作、其他控件完整属性 | 取同基线单项开关/复原对照，见 validation 与 acceptance |
| 5026 字段写入 | 先识别实际 MCP 序列化路径和派生字段，当前拒绝不等于永远不可编辑 |
| 跨窗口控件、资源注入/清理、完整报表 | 先查引用、资源归属及全局 ID；已有克隆入口不能替代这些工作 |
| 旧版本、ESET、扩展长度 | 明确报告当前兼容范围；失败窗口不得当空窗口 |

开发次序依实际需求选择。一般先将已有几何证据落到受限实现并补强只读检查，再推进变量/通道引用链；动作或特殊控件需求明确时再补对应单项实验，不以类型数量作为完成标准。
